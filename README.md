# Reference Data Management System

A comprehensive web application for managing reference data in financial markets, built for Barclays Global Markets.

## Features

### IPMDM (Investment Product Master Data Management)
- Reference Data Input and Tracking
- Data Validation and Enrichment
- Reference Data Monitoring
- Reporting and Analytics
- Integration with Trade Systems
- User Access and Security
- Compliance and Regulatory Standards

### CAMDM (Client and Account Master Data Management)
- Reference Data Input and Tracking (SSIs and Entity Data)
- Data Validation and Enrichment
- Reference Data Monitoring
- Reporting and Analytics
- Integration with Trade Systems
- User Access and Security
- Compliance and Regulatory Standards

## Tech Stack

- React 18
- TypeScript
- Material-UI
- Redux Toolkit
- React Router
- Chart.js

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone [repository-url]
cd reference-data-management
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Start the development server:
```bash
npm start
# or
yarn start
```

The application will be available at `http://localhost:3000`.

### Building for Production

To create a production build:

```bash
npm run build
# or
yarn build
```
